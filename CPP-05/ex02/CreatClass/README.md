
# About 
this script is for creat a two files Name.hpp and Name.cpp with the required member function in OCCF

# how to use the script

run the following command in the parent directorie of the folder CreatClass

like this `./CreatClass/PrepareClass.sh` followed with the option -c (stands for concrete) and the name that you want to name your class
ex `./CreatClass/PrepareClass.sh -c name`
and the output in your current directorie will appear like:
