## 📌 Overview
**CPP Module 08** is part of the Object-Oriented Programming curriculum at 1337 (42 Network). 

As a Software Engineer, transitioning from procedural to Object-Oriented Design (OOD) is critical. This specific module dives into the nuances of C++98, ensuring strict memory safety and adherence to the Orthodox Canonical Class Form.

## 🛠️ Usage
Compile the exercises inside this module using make. Each exercise contains its own executable to demonstrate the concepts learned.

`ash
cd ex00
make
./a.out
`
